USER MODULE - COMPLETE FILE LIST
================================

This file lists all files that are part of the User Module and should be included when integrating with the main RentMe project.

├── views.py
├── urls.py

SETTINGS CONFIGURATION (REQUIRED in main project)
-------------------------------------------------
In settings.py:
- Add 'users' to INSTALLED_APPS
- Add 'rest_framework' to INSTALLED_APPS
- Add 'corsheaders' to INSTALLED_APPS
- Set AUTH_USER_MODEL = 'users.User'
- Configure REST_FRAMEWORK settings
- Configure MEDIA_URL and MEDIA_ROOT
- Configure CORS settings
- Configure SESSION settings

URL CONFIGURATION (REQUIRED in main project)
--------------------------------------------
In main urls.py:
- Add path('api/users/', include('users.urls'))
- Add media URL patterns for development
- Add template view URLs (optional)

INTEGRATION STEPS
-----------------
1. Copy users/ directory to main project
2. Copy templates/users/ directory (if using template views)
3. Create media/profile_pictures/ directory
4. Update settings.py with User Module configuration
5. Update urls.py with User Module URLs
6. Install dependencies (pip install -r requirements.txt)
7. Run migrations (python manage.py makemigrations users && python manage.py migrate)
8. Create superuser (python manage.py createsuperuser)
9. Test API endpoints
10. Verify integration with other modules

FILES TO EXCLUDE (Not part of User Module)
------------------------------------------
- venv/ (virtual environment)
- db.sqlite3 (database file)
- __pycache__/ (Python cache)
- *.pyc (Python compiled files)
- Test scripts (login_test.py, test_api.py, etc.)
- Documentation files not listed above
- Configuration files specific to this project setup
